1. PURPOSE

Настоящий контракт фиксирует правила выполнения работ в рамках перехода к Pilot Version:

1000 О.К. нагрузка
20k R.U. транзакций/сутки
полная интеграция Sandbox → PDA → Backend → acts_log → Replay

Главный принцип:

никакая часть системы не имеет права быть источником истины, кроме acts_log.

Все действия обязаны проходить цепочку:

→ Service Execution

9. REPLAY CONTRACT

Replay Engine обязан:

восстанавливать систему 100% из acts_log
не использовать frontend state
не использовать service cache
обеспечивать deterministic output

Failure condition:

любое расхождение = system invalid state
