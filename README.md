# Pygmalion / C.R.I.S.T.A.L.L. - v0.4.03 "Crystal Bridge"

## Обзор

`backend-v0.4.03.Crystal Bridge` является переходной версией между `v0.3.26.05`, превосшедшей `v0.4.02.GENEZIS` и актуальной версией канона.

Эта документация описывает текущее состояние и карту миграции.

## Архитектурные слои

Следующие слои определены в CANON:

Human Will
↔ DAP/PDA
↔ Services
↔ Canon Layer
↔ Repository
↔ acts_log

`acts_log` выступает как SSOT и оркестратор для миграции компонентов.

## Жизненный цикл решения

Каждое архитектурное решение проходит 4 стадии:

Preview
↔ Confirmation
↔ Execute
↔ Replay

Этот README охватывает всё до стадии Execute.

## Границы

В рамках Crystal Bridge запрещено:

- Изменять CANON.md;
- Изменять acts_log;
- Изменять файловые операции;
- Использовать Write-Bypass;
- Выполнять SQL-операции в обход миграционных скриптов;
- Принимать архитектурные решения без прохождения 4 стадий.

В дальнейшем, при переходе к v0.5, acts_log станет единственным источником версий и будет проходить через утверждение CANON.
