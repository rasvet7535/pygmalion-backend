### I. ПОДТВЕРЖДЁННЫЙ ИНФРАСТРУКТУРНЫЙ БАЗИС (FACT)

1. **Порт СУБД (PostgreSQL):** Каноническим портом для сопряжения СУБД с ядром GENEZIS в текущей сборке утверждается **`5434`** (внутренний порт контейнера `5432` мапится как `5434:5432`). Любые упоминания порта `5433` в предыдущих документах признаются устаревшей гипотезой (HYPOTHESIS) и исключаются из рабочих файлов.
2. **Статус Replay Test (UNKNOWN):** Текущий статус выполнения Replay на реальной СУБД классифицируется строго как **не подтверждённый**. Исторические данные о прохождении тестов с результатом `0 mismatch` не могут быть автоматически приняты без проведения ручной верификации в текущем контуре.
3. **Совместимость API (HYPOTHESIS):** Полная совместимость эндпоинтов фронтенда Золотой песочницы (запросы к `/api/threshold`) со службами `ThresholdService` и `ok.js` в GENEZIS является рабочей гипотезой и требует инструментального подтверждения в процессе интеграции.

### IV. ЖЁСТКИЙ РЕГЛАМЕНТ БЕЗОПАСНОСТИ ДЛЯ ИИ-АГЕНТОВ (Forbidden Zone)

В соответствии с правилами Engineering Governance v1.0, агентам (включая Jules и Codex) строго запрещено самовольное выполнение (Execute) кода миграции без предварительного одобрения человека:

* **Разрешено (Allowed):** Анализ кода, составление детальных планов миграции, точечная проверка синтаксиса в режиме Read-Only.
* **Запрещено (Forbidden):** Запись в файлы вне папки `docs/`, изменение Git-индекса, перезапуск Docker-контейнеров, модификация схем СУБД, изменение `package.json` и перезапись `CANON.md` / `acts_log`.

Каждый шаг переноса должен следовать строгому циклу:  
`Human Will` → `DAP/PDA` → `Preview` → `Confirmation` → `Execute` → `Replay`.
